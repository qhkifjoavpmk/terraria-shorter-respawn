## Overview

Shorter Respawn gives server operators granular control over respawn delay curves, allowing quick respawns during casual sessions and scaling timers for harder boss encounters.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Terraria Shorter Respawn** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Per-Boss Timers** | Set distinct respawn delays for each boss fight phase |
| **Server Config** | TOML config file hotloads without restarting the server |
| **Difficulty Scaling** | Respawn time scales with world difficulty and player death count |
| **Mod Menu Support** | In-game slider UI when Mod Config mod is installed |
